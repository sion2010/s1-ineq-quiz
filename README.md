# 簡易不等式教學建議

404 原因：GitHub Pages 仲未開，或個倉庫之前只有 README。

你要手動開 Pages：
1. 開 https://github.com/sion2010/s1-ineq-quiz/settings/pages
2. Build and deployment → Source 選 **Deploy from a branch**
3. Branch 選 **main**，資料夾選 **/ (root)**
4. Save
5. 等 1–2 分鐘再開 https://sion2010.github.io/s1-ineq-quiz/

要有 `index.html`、`quiz_data.js`、`quiz_app.js` 三個檔。
